# CookMate 🍳

CookMate est une application web qui vous aide à trouver des idées de recettes à partir des ingrédients que vous avez chez vous.

## 🚀 Fonctionnalités

- 🥕 **Sélection d'ingrédients** : Recherche rapide et sélection par cases à cocher.
- 🎯 **Calcul de score** : Affichage du pourcentage d'ingrédients possédés pour chaque recette.
- 📋 **Liste des ingrédients manquants** : Visualisation directe de ce qu'il vous manque pour cuisiner.
- 📖 **Détail des recettes** : Temps de préparation et instructions pas à pas.

## 🛠️ Technologies

- **Frontend** : React, React Router, CSS3
- **Backend** : Node.js, Express
- **Données** : JSON

## 💻 Démarrage en local

### 1. Cloner le projet
\\\ash
git clone https://github.com/VOTRE-USERNAME/cookmate.git
cd cookmate
\\\

### 2. Lancer le Frontend
\\\ash
cd frontend
npm install
npm start
\\\
L'application sera accessible sur \http://localhost:3000\.

### 3. Lancer le Backend (optionnel)
\\\ash
# Depuis la racine
npm install
npm run dev
\\\
Le serveur tourne sur \http://localhost:4000\.
